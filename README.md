================================================================
LAUE - программа для обработки лауэграмм
================================================================

НАЗНАЧЕНИЕ
----------
Программа предназначена для работы с рентгеновскими лауэграммами:
просмотр, моделирование и обработка картин дифракции метода Лауэ,
а также работа со стереографической (сеткой Вульфа) проекцией,
используемой при анализе симметрии и ориентировке кристаллов.

Программа разработана Н. В. Сомовым (ННГУ им. Н. И. Лобачевского)
и входит в комплекс лабораторных работ по кристаллографии
(лабораторный практикум кафедры кристаллографии и
экспериментальной физики ННГУ; см. "Кристаллография.
Лабораторный практикум" / под ред. Е. В. Чупрунова. -
М.: Физматлит, 2005).


СОСТАВ ПРОЕКТА
--------------
Laue.dpr             - главный файл проекта Delphi;
Laue.cfg, Laue.dof,
Laue.dproj           - файлы настроек проекта;
BASE.pas, .dfm       - основное рабочее окно программы;
LauGram.pas, .dfm    - работа с лауэграммой;
Wulf.pas             - построение и работа с сеткой Вульфа;
WideWulf.pas, .dfm   - увеличенное изображение сетки Вульфа;
Ustir.pas            - модуль юстировки (установки) образца;
Formula.pas          - расчётные формулы (геометрия метода Лауэ);
Options.pas, .dfm    - окно настроек;
Setting.pas, .dfm    - окно параметров измерения;
Additional.pas, .dfm - вспомогательные функции;
ABOUT.pas, .dfm      - окно "О программе";
Pro1.LGM             - пример файла данных лауэграммы;
X-Ray.hlp            - файл справки (старый формат WinHelp);
LAUE.BMP, Лауэ.bmp   - иллюстрации;
Laue_Icon.ico, Icon2.ico - значки программы;
LICENSE              - текст лицензии Apache 2.0.


СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
Операционная система: Windows.
Для сборки из исходных текстов требуется среда разработки
Delphi (проект создан в Borland/Embarcadero Delphi).
Программа может быть собрана также в Lazarus (Free Pascal)
после небольшой адаптации VCL-форм.


СБОРКА
------
1. Откройте файл проекта Laue.dpr в среде Delphi.
2. Выполните команду Compile (или Run) из меню Project.
3. Полученный исполняемый файл Laue.exe готов к работе.


ФАЙЛЫ ДАННЫХ
------------
Данные лауэграмм хранятся в файлах с расширением .LGM.
Пример файла данных - Pro1.LGM.


СПРАВКА
-------
Файл справки X-Ray.hlp выполнен в устаревшем формате WinHelp
и напрямую не открывается в современных версиях Windows.
Для его просмотра используйте сторонние просмотрщики WinHelp
или конвертируйте файл в современный формат (HTML Help).
